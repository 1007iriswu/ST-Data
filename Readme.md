# CMoney ETF 資料檢視器 (CMoney ETF Data Viewer)

這是一個基於 React 和 Express 開發的全端應用程式，專門用於即時檢視 CMoney API 提供的台灣 ETF 相關財務數據。

## 主要功能

*   **即時數據抓取**：透過後端代理 (Proxy) 繞過 CORS 限制，直接從 CMoney API 獲取最新資料。
*   **資料來源透明化**：在介面上直接顯示原始 API 數據網址，方便驗證。
*   **互動式表格**：
    *   **標題排序**：點擊表格標題可進行智慧排序（支援數字與文字）。
    *   **個股詳情連結**：點擊標的代號可直接開啟 Goodinfo! 台灣股市資訊網查看詳情。
*   **Google Sheets 匯出**：
    *   **一鍵匯出**：將 ETF 持股資料直接匯出至 Google 試算表。
    *   **匯出模式選擇**：支援「匯出至新檔案」或「取代現有檔案」（自動搜尋同名檔案並更新）。
    *   **內建 GAS 指南**：當未設定 GAS 網址時，提供完整的 Google Apps Script 設定教學與程式碼。
*   **多樣化檢視模式**：
    *   **表格模式 (Table View)**：適合快速掃描大量數據。
    *   **網格模式 (Grid View)**：適合詳細查看單一記錄。
*   **ETF 選單切換**：預設提供 14 種熱門 ETF（如 0050, 0056, 00878 等）供快速選擇。
*   **自定義資料來源**：
    *   使用者可以自行新增 ETF 代碼與顯示名稱。
    *   自定義來源會自動儲存於瀏覽器的 `localStorage`，重新整理頁面後依然存在。
    *   提供「恢復預設值」功能，可隨時重置選單。
*   **響應式設計**：採用 Tailwind CSS 打造，支援手機、平板與桌機瀏覽。
*   **流暢動畫**：使用 `motion` 庫實現狀態切換時的平滑過場動畫。

## 技術架構

*   **前端**：React, TypeScript, Tailwind CSS, Lucide React (圖示), Motion (動畫)。
*   **後端**：Express (Node.js)，負責 API 代理轉發，確保資料抓取穩定。
*   **開發工具**：Vite。

## 如何使用

1.  在首頁上方的下拉選單中選擇想要查看的 ETF。
2.  點擊「重新整理 (Refresh)」按鈕獲取最新數據。
3.  切換表格或網格圖示來改變顯示方式。
4.  **資料分析與導航**：
    *   點擊表格 **標題** 進行排序。
    *   點擊 **標的代號** 開啟 Goodinfo 詳情頁面。
    *   點擊 **資料來源** 網址查看原始 JSON。
5.  點擊 **「Sheet」** 按鈕匯出資料：
    *   首次使用請按照彈窗指南設定 **Google Apps Script (GAS)**。
    *   選擇「匯出至新檔案」或「取代現有檔案」。
6.  點擊齒輪圖示 (Settings) 進入「管理資料來源」面板，新增或刪除自定義的 ETF 代碼。

## Google Apps Script (GAS) 設定

為了實現匯出至 Google Sheets，您需要部署一個簡單的 GAS 網頁應用程式：

1.  建立 GAS 專案並貼入應用程式中提供的程式碼。
2.  部署為「網頁應用程式」，權限設為「所有人」。
3.  將產生的網址設定為環境變數 `GAS_WEB_APP_URL`。
